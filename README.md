# Netflix Movies and TV Shows Data Analysis

## Project Overview

This project analyzes the Netflix Movies and TV Shows dataset using Python, Pandas, and Matplotlib.

The objective of this project is to explore Netflix's content library and identify patterns related to content types, genres, countries, release years, ratings, directors, and actors.

## Dataset

The dataset contains information about Netflix movies and TV shows, including:

* Title
* Director
* Cast
* Country
* Release year
* Rating
* Duration
* Genre
* Date added
* Content type

## Key Findings

* The dataset contains **8,807 Netflix titles**.
* There are **6,131 Movies** and **2,676 TV Shows**.
* Movies represent approximately **69.63%** of the dataset.
* TV Shows represent approximately **30.37%**.
* **International Movies** are the most common genre.
* The **United States** has the highest number of titles in the dataset.
* **TV-MA** is the most common content rating.
* **2018** has the highest number of titles by release year.
